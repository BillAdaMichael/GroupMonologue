This was a 2 day game jam project for the University of Otago OCSS. It is a VR game and does not currently have a compiled binary to one-click run it. However, the project should be able to run with minimal setup.

The game is a social evolution project. It is meant to be played as a co-op couch experience with at least 3 people.

## Steps to run:

1.  Clone the `main` branch
2.  Load the scene into unity hub and download the editor version `6000.3.24.f1` (although any LTS supported 6.3 version should work
3.  Open the project and load scene `MainScene2`
4.  Launch connect your headset to your PC and launch steamVR
5.  Start the Unity scene

It should start the game in steamVR now. Just follow the instructions on the computer!

## Sharing your recordings:
The recordings are placed under `testFolder` under the unity project (not inside the assets, in the project parent). If you want to send your recordings to someone else, just zip that folder and send it over! Or share the .csv files if you want to send individual recordings.
